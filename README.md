# 🌌 Star Wars Memory Game

Интерактивная игра на память в сеттинге **Звёздных Войн** (Star Wars Memory Card Game). Игроку необходимо находить парные карточки с персонажами и объектами саги, затрачивая как можно меньше ходов. 

При отгадывании последней пары запускается анимация гиперпрыжка (ускорение звёздного фона), воспроизводится Имперский марш и открывается окно победы.

---

## 🚀 Особенности (Features)

- 🃏 **Игровой процесс:** 16 карт (8 уникальных пар) с персонажами Вселенной Звёздных Войн.
- 💫 **Динамический фон:** Звёздное поле на Canvas с эффектом гиперпрыжка при победе.
- 🔊 **Звуковое сопровождение:**
  - Звук переворачивания карточки.
  - Звук успешного совпадения пары.
  - Легендарный Имперский марш при победе.
- 🏆 **Таблица лидеров (Leaderboard):** Автоматическое сохранение топ-10 лучших результатов в `localStorage`.
- 🎨 **Модульные стили:** Использование SCSS с архитектурой, близкой к 7-1 (abstracts, base, components, layout).

---

## 🛠 Стек технологий (Tech Stack)

- **JS / Build:** JavaScript (ES6+), Vite
- **Styles:** SCSS / BEM
- **Markup:** HTML5, ARIA-атрибуты доступности
- **Storage & Audio:** LocalStorage API, HTML5 Audio

## 🔧 Локальный запуск (Local Setup)

1 Клонируйте репозиторий:
```bash
   git clone [https://github.com/skif-cezar/memory-game.git](https://github.com/skif-cezar/memory-game.git)

2 Переключитесь на ветку memory-game:
git checkout memory-game

3 Перейдите в директорию проекта:
cd memory-game

4 Установите зависимости:
npm install

5 Запустите сервер разработки:
npm run dev

6 Откройте адрес http://localhost:3000 в браузере.
